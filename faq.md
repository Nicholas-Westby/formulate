# Frequently Asked Questions

* Which versions of Umbraco does Formulate support?
  * Formulate 5 supports Umbraco 17.6 or later, Umbraco 18 and Umbraco 19. See [Requirements](/requirements).
* Does Formulate require AngularJS?
  * No. Formulate 5 renders forms with plain JavaScript and has no front-end dependencies.
* Can I use Formulate on a site built with jQuery, Foundation or some other framework?
  * Yes. Formulate doesn't depend on any front-end framework. You can write your own styles, or turn on the [basic theme](/pro/basic-theme).
* Do I still need Formulate Pro?
  * No. Formulate Pro is now part of Formulate, for free. Designed Emails and the basic theme are in the main package. See [What's New in Formulate 5](/whats-new-in-5).
* Does Formulate send any usage data?
  * No. Formulate 5 doesn't send any usage data anywhere.
* Can I import my Formulate 3 forms into Formulate 5?
  * Not yet. There is no automatic import in Formulate 5.0. See [Upgrading from Formulate 3](/whats-new-in-5#upgrading-from-formulate-3).
* Where do I ask questions or report problems?
  * Open an issue on [GitHub](https://github.com/Nicholas-Westby/formulate/issues).
* Can Formulate be used on a production site?
  * Yes. Formulate 3 is used on many sites.
