# Formulate

Formulate is a form builder for Umbraco. You build forms in the back office, lay them out,
and add them to pages with a form picker. When a visitor submits a form, its handlers act
on the data, for example by sending an email or storing the submission.

## Install

Formulate 5 requires Umbraco 17.6 or later. Add the main package to your Umbraco site:

```
dotnet add package Umbraco.Community.Formulate
```

The other `Umbraco.Community.Formulate.*` packages are parts of Formulate that the main package brings in.
